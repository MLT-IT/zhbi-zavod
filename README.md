# Общестрой

### Информация о ветках в git

* Ветка `prod` - это то, что сейчас на хостинге (production).

* Ветка `dev` - это еще незалитые изменения, которые пока делаются / согласовываются (development).

* Ветка `master` не используется, ее можно удалить (у меня нет полномочий удалить ветки в удаленном репозитории).
