# Общестрой

### Информация о ветках в git

* Ветка `master` (production) - это то, что сейчас на боевом хостинге.

* Ветка `dev` (development) - это еще незалитые на боевой хостинг изменения, которые пока делаются / согласовываются на локалке или на тестовом сайте. Ветка может отставать от master, это значит, что последние изменения были не очень сложными и не очень рискованными, поэтому их сразу вносили на боевой сайт.

### Полезные скрипты

В папках `_dev/Полезные скрипты` и `_dev/Старые скрипты` находятся полезные скрипты, которые выполняются в console. Они помогают выполнить задачи, которые нельзя выполнить через Rebatcher или msPre. Задачи, которые очень долго выполнять вручную. Эти скрипты могут быть полезны и на других сайтах (не только на Общестрое).
