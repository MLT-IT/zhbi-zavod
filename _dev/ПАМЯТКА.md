#### Добавлене товаров кратно кол-ву на поддоне
11.04.2022

Я отключил изменение кирпичей по кол-ву в поддоне. 
Чтобы включить, нужно в файле `\_src\js\index.js` раскомментировать строку:
```
// $item.attr('data-step', step);
```

Но в корзине свой код. Чтобы работало в корзине, нужно в файле `\core\elements\sections` раскомментировать вот этот участок:
```
{*{if $coefficient?} data-step="{$coefficient}"{/if}*}
```
